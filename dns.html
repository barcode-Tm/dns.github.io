چگونه از DNS استفاده کنم؟

برای استفاده از سرورهای DNS پیشنهادی، آدرس IP را کپی کرده و در تنظیمات شبکه دستگاه خود وارد کنید. برای اطلاعات بیشتر به منابع آنلاین مراجعه کنید.

نکات مهم

  • برای بهترین عملکرد، از سرورهای DNS با کمترین پینگ استفاده کنید.
  • در برخی موارد، استفاده از سرورهای DNS رایگان ممکن است محدودیت‌هایی داشته باشد.
  • اگر با یک سرور DNS مشکل داشتید، سرور دیگری را امتحان کنید.
